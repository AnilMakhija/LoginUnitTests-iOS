# 🔐 LoginUnitTests-iOS

A Swift-based iOS project showcasing the usage of unit tests for login functionality — perfect for developers looking to improve testing strategies for authentication features.

---

## 🚀 Overview

This project demonstrates:

- ✅ Writing unit tests for login features  
- ✅ Unit test coverage for username validation, password validation, and API authentication  
- ✅ Test-driven development (TDD) approach for iOS authentication workflows  
- ✅ Example of a clean, testable Swift architecture

---

## 🧑‍💻 Features

- Unit tests for login validation logic  
- Mock network requests for API authentication  
- Test coverage for common edge cases (empty fields, incorrect credentials)  
- Swift-based UI and authentication flow integrated with test cases

---

## 🛠 How to Use

### Clone the repo

```bash
git clone https://github.com/AnilMakhija/LoginUnitTests-iOS.git
cd LoginUnitTests-iOS
```

### Open in Xcode

- Open `LoginUnitTests-iOS.xcodeproj`
- Build and run the tests using Xcode's test navigator
- Check the results for unit test execution

### Run Unit Tests

- Open Xcode's **Test Navigator** (`Cmd + 6`)
- Run the tests by selecting **Product > Test** or use the shortcut `Cmd + U`
